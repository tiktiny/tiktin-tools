# אפליקציה ראשית — משרד טיקטין

פורטל הכניסה לכלי המשרד. כל כלי נפתח בלשונית חדשה ונשאר עצמאי.

האתר: https://tiktiny.github.io/tiktin-tools/

ארבעת השמות המאושרים נמצאים ב־`initialApps` בתוך `index.html`.
בכל פתיחה הפורטל בודק את המאגרים הציבוריים של `tiktiny` ומוסיף מאגרים חדשים עם GitHub Pages פעיל. הכותרת שלהם נלקחת מתיאור המאגר. מאגרים בארכיון והפורטל עצמו אינם מוצגים. אם GitHub API חסום או מוגבל, ארבעת הקישורים הבסיסיים ממשיכים לעבוד.

כאשר מוסיפים אפליקציה חדשה, יש להוסיף אותה גם ל־`initialApps` עם שם עברי מאושר וקישור קבוע כדי שתופיע גם בלי זמינות ה־API. יש לאמת את הקישור לאחר פרסום. פרסום: GitHub Pages, ענף main, root.
